Guardian SPGC-220 (single-phase)

Overview

Smart fixed-speed controller for single-phase 200–250 VAC FE Petro (and similar) STPs; also runs DEF-PMA150A/B in DEF Mode (SW2 P6, firmware 0.3.8+). MUST be calibrated before use: close the STP valve, hold Silence/Calibrate ~10 s until 'CAL'/kW alternates, lift a dispenser handle, ~16 s snapshot → 'run'/~100±5%. Reset = hold ~3 s until display blanks. Rotary SW5 stays at 0 unless FE Tech Support says otherwise. With TPI/EVO ATG control, leave Auto Restart, Fault Shutdown, Primary-Secondary and Alternating Circuit switches OFF — the FMS handles them.

Source

Franklin Fueling Systems Single-Phase Guardian Series Controller Installation Guide, doc 223987103

Guardian SPGC-220 (single-phase) · fault

Fault code UL

Underload (dry run)

Likely cause

Motor watts below the calibration value — typically dry running from an empty tank or clogged intake, or a bad calibration.

Action

Check fuel level — under 8", schedule a delivery. Hold Reset until the display blanks. If the STP won't run, use Bypass Mode (SW1 P7) to test, then recalibrate. SW1 P8 (Auto Restart) can auto-retry after UL — but never with TPI.

Guardian SPGC-220 (single-phase) · fault

Fault code Lr

Locked rotor (at startup)

Likely cause

Motor watts above range at start — debris or a damaged PMA rotor, or bad calibration.

Action

Reset. If it recurs: lock out power, pull the extractable, remove the PMA end-bell cap and spin the rotor with an Allen wrench. Binding → replace the PMA and recalibrate; spins free → contact FE Tech Support.

Guardian SPGC-220 (single-phase) · fault

Fault code OL

Overload (while running)

Likely cause

Motor watts above range while running — same causes as Lr.

Action

Same flow as Lr: reset, verify, inspect/spin the rotor, replace PMA if bound, recalibrate (always recalibrate after a PMA change, even same HP).

Guardian SPGC-220 (single-phase) · fault

Fault code LI

Low incoming voltage

Likely cause

Supply below 185 V on L1/L2.

Action

Self-resets once supply is back above 200 V. Verify 200–250 VAC across L1/L2; fix supply wiring if out of range. If connected to an ATG, compare the calibrated voltage (Control Pumps menu) to measured — off by >10 VAC, recalibrate.

Guardian SPGC-220 (single-phase) · fault

Fault code HI

High incoming voltage

Likely cause

Supply above 260 V on L1/L2.

Action

Self-resets below 245 V. Same checks as LI — verify the 200–250 VAC supply.

Guardian SPGC-220 (single-phase) · fault

Fault code OC

Open circuit

Likely cause

Hook signal present but no motor load — broken output wiring/relay, or the PMA thermal overload opened after a locked-rotor event.

Action

Reset. If it recurs: lock out power and check the output connections and motor circuit continuity end-to-end; allow a tripped thermal overload to cool, then recheck.

Guardian SPGC-220 (single-phase) · fault

Fault code Er

Extended run

Likely cause

Ran 60 consecutive minutes with no change in power consumption (stuck hook signal or genuine long-run use).

Action

Check for voltage across the hook terminals with all handles off — if present, have an electrician correct it. For legitimate long-run sites (e.g. generators), SW2 P5 disables Extended Run — but NEVER disable it where the pump must stop for mechanical or electronic line leak detection.

Guardian SPGC-220 (single-phase) · fault

Fault code rEL

Relay fault

Likely cause

PMA is running without a proper hook signal — typically a failed Smart Controller relay contact.

Action

Hold Reset until the code dims. If it recurs, lock out power and replace the SPGC-220 relay board; if it still faults, contact FE Tech Support.

Guardian SPGC-220 (single-phase) · status

Status IdLE Power on, pump off

Idle. If IdLE shows while a dispenser is on, check the hook terminals (120–240 VAC expected) and switch settings; if correct, contact FE Tech Support.

Guardian SPGC-220 (single-phase) · status

Status run Pump running

Alternates 'run' and percent-of-calibration. If it shows run with all dispensers off, power may be present at the hook terminal — contact FE Tech Support.

Guardian SPGC-220 (single-phase) · status

Status unc Uncalibrated

Controller has not been calibrated — perform the calibration procedure before use.

Guardian SPGC-220 (single-phase) · status

Status CAL Calibrating

Alternates 'CAL' and the kW reading of the attached motor during calibration.

Guardian SPGC-220 (single-phase) · configuration

DIP switch settings

SW1 pole 1–5. ON: Address bits 1/2/4/8/16 for Primary-Secondary or Alternating Circuit sets. OFF: —. Factory: OFF. Each controller in a set needs a unique address.

SW1 pole 6. ON: Fault Readout Mode — display steps through the last five faults. OFF: Normal operation. Factory: OFF

SW1 pole 7. ON: Bypass — diagnostics bypassed for 10 minutes (testing only). OFF: Normal operation. Factory: OFF

SW1 pole 8. ON: Auto Restart after an underload (UL) once the hook cycles. OFF: Stay down after UL until manual reset. Factory: OFF. Do NOT use with TPI — the FMS handles restarts.

SW2 pole 1. ON: Fault Shutdown: any fault shuts down ALL controllers in the set (set on Primary only). OFF: A fault stops only the faulted controller. Factory: OFF. Required with Veeder-Root PLLD in Primary-Secondary.

SW2 pole 2. ON: Unused. OFF: —. Factory: ON. Default position is ON.

SW2 pole 3. ON: This unit is the PRIMARY in Primary-Secondary. OFF: Secondary or stand-alone. Factory: OFF

SW2 pole 4. ON: This unit is the Primary of an Alternating Circuit set. OFF: Secondary / stand-alone. Factory: OFF

SW2 pole 5. ON: Disables Extended Run detection. OFF: Extended Run active (60-min limit). Factory: OFF. CAUTION: never disable where the pump must stop for line leak detection.

SW2 pole 6. ON: DEF Mode — DEF-PMA150A/B submersibles only. OFF: Petroleum motors. Factory: OFF. Firmware 0.3.8+. Set BEFORE calibrating DEF units.

SW2 pole 7–8. ON: Unused. OFF: Leave OFF. Factory: OFF

SW5 pole rotary. ON: —. OFF: Leave at position 0. Factory: 0. Moving it off 0 without FE Tech Support direction can break calibration and operation.
