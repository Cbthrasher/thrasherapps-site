E1

The dispenser database failed its integrity check. Data the dispenser relies on cannot be trusted. Action: record the current totals and configuration before doing anything, because recovery may clear them; power cycle and see whether the fault clears on a clean start; check for an unstable supply or repeated power interruptions, which is the usual root cause of corruption; check for a recent interrupted software download; reload the database from the site controller if the dispenser supports it; verify every price, grade and configuration value afterwards rather than assuming the reload was complete; if it recurs the board is suspect, so escalate rather than repeatedly reloading; check calibration and metrological settings survived, since a database rebuild can restore defaults

Gilbarco · 700s

E2

Flash memory has failed its integrity check. The dispenser's stored program or data is not reliable. Action: record configuration and totals before attempting recovery; power cycle and see whether the fault repeats on a clean start; check the supply for instability or repeated interruptions, which corrupts flash during writes; check whether a software download was interrupted, since that is the most common single cause; reload the software using the correct version for this dispenser and let it finish without interruption; if flash fails again after a clean reload, the board is failing and needs replacing; verify calibration and configuration after any recovery

E3

The internal LON network configuration does not match what the dispenser expects. Nodes are either missing, duplicated or addressed wrongly. Action: check which nodes are expected for this dispenser build and which are actually reporting; check node addressing for duplicates, which is common after a board swap; check the LON wiring and terminations between nodes, including anything disturbed by recent work; check node software versions are compatible with the main board; reseat each node and its connectors; power cycle and let the network re enumerate; if a node was deliberately removed, correct the configuration to match

Gilbarco · 700s

E4

One or more internal software tasks did not start. The dispenser has come up incomplete rather than failed outright, which is why some functions may appear to work. Action: power cycle and see whether it comes up clean; check for an interrupted or partial software download; check the supply is stable and adequate, since a brownout during boot causes this; check for a hardware fault preventing a subsystem initialising, particularly a node that is not responding; reload the software if it repeats; escalate if it persists after a clean reload, since this points at the board

Gilbarco · 700s

E5

A cold start was forced, so the dispenser restarted and cleared its working state. Action: establish whether the cold start was deliberate, since a technician performing one is normal and needs no action; if nobody forced it, check the supply for interruptions, brownouts or a failing power supply; check the incoming voltage under load rather than at rest; check for loose or corroded supply terminations in the dispenser; verify configuration, prices and calibration survived, and re enter anything lost; if cold starts repeat without cause, treat the power supply as suspect

Gilbarco · 700s

E6

The redundant copies of stored data do not agree. The dispenser keeps a second copy specifically so it can detect this. Action: record the current configuration and totals; power cycle and see whether it resolves to a consistent copy; check the supply for instability, which is the usual cause of a write completing to one copy and not the other; check for an interrupted software download or a cold start during a write; verify all values against your records afterwards rather than trusting whichever copy won; if it recurs, the memory or the board is failing

Gilbarco · 700s

E7

A firmware upgrade was attempted with the calibration switch not engaged. The dispenser blocks this deliberately, because firmware affects metrology and the switch is what proves a sealed setting was opened knowingly. Action: this is a procedural block rather than a fault, so nothing is broken; confirm you are authorised to break the Weights and Measures seal before proceeding; engage the calibration switch, repeat the upgrade, and let it complete without interruption; verify calibration and configuration after the upgrade; Breaking a Weights and Measures seal to reach calibration is restricted to a registered service agent in most states, so confirm you are permitted before opening it, and arrange resealing and any required W&M notification afterwards

Gilbarco · 700s

E8

The database changed and the dispenser has applied default values in place of what was there. Anything not explicitly reconfigured is now at default, including values that matter for billing. Action: treat every configurable value as suspect and check it, do not spot check; verify unit prices, grade mapping, volume units and flow settings before allowing sales; verify calibration and ATC settings, since defaults here have metrological consequences; establish what caused the change, commonly a software update, a cold start or a corrupted database; check the supply if this followed a power event; Breaking a Weights and Measures seal to reach calibration is restricted to a registered service agent in most states, so confirm you are permitted before opening it, and arrange resealing and any required W&M notification afterwards

Gilbarco · 700s

E9

RAM has failed its integrity check. Nothing the dispenser reports can be relied on while this is present. Action: power cycle and see whether it comes up clean; record what configuration can still be read; check the supply for instability and check for overheating in the electronics enclosure; check the board for physical damage, corrosion or water ingress, which is common in coastal and high wash sites; if RAM fails again after a clean restart the board needs replacing, so do not keep clearing it; verify configuration and calibration fully after any recovery

Gilbarco · 700s

E10

The hardware present does not match the hardware the configuration describes. Action: list what the configuration expects and compare it against what is physically fitted; check whether a board, node or module was recently swapped for a different variant; check part numbers and software versions of any replaced component, since a superficially identical board can be a different variant; correct either the configuration or the hardware so they agree; power cycle and confirm the dispenser enumerates everything it expects

Gilbarco · 700s

E12

Calibration factors were restored from door node storage. The dispenser has recovered metrological data from its backup copy rather than from its own memory. Action: verify the restored calibration is actually correct rather than assuming the backup was current; check the restored values against your records and the last calibration certificate; run a meter proving test before returning the dispenser to sale, since restored calibration has not been proven on this hardware; establish why the primary copy was lost, usually a board swap, a corrupted database or a power event; Breaking a Weights and Measures seal to reach calibration is restricted to a registered service agent in most states, so confirm you are permitted before opening it, and arrange resealing and any required W&M notification afterwards

Gilbarco · 700s

11

Two wire communication between the dispenser and the site controller has failed. Corroded or damaged two wire cabling causes most of these, not the boards at either end. Action: check the two wire cable and its terminations at both ends for corrosion, water and loose screws, starting at the dispenser junction box; check for water in the junction box, which is the single most common cause; check polarity, since a reversed pair after recent work will not communicate; check the cable for damage where it passes through the island and conduit, including anything crushed during construction; check the site controller is powered and that other dispensers on the same loop are working, which tells you whether the fault is site wide or local; check for a shorted or grounded conductor, and megger the pair if the fault is intermittent; only suspect the interface board once the cable is proven

20

The pulser and product mapping disagree, so either a pulser is connected and its product is not mapped, or a product is mapped and its pulser is not connected. Action: check the pulser is connected and its harness is seated at both ends; check the product mapping in programming against what is physically plumbed to that meter; check the pulser harness for damage, chafing or a pinched conductor; check whether a recent meter or pulser replacement was left unmapped; confirm the pulser type matches what the configuration expects; correct whichever side is wrong and power cycle to confirm

The volume unit type has not been set. The dispenser does not know what unit it is measuring in, which makes everything it reports meaningless. Action: set the volume unit correctly for the jurisdiction before allowing any sale; verify the setting against what the site is required to sell in; check whether the value was lost rather than never set, which points at a database or power problem; verify calibration and totals after setting it; Breaking a Weights and Measures seal to reach calibration is restricted to a registered service agent in most states, so confirm you are permitted before opening it, and arrange resealing and any required W&M notification afterwards

The pump is not calibrated. It cannot legally be used for sale in this state. Action: do not return the dispenser to sale until it is calibrated and proven; establish whether calibration was lost or never performed, since lost calibration points at a database, board or power problem that will recur; check whether a recent board swap or software update cleared it; calibrate and prove the meter using the correct test measure procedure; record the calibration and arrange resealing; Breaking a Weights and Measures seal to reach calibration is restricted to a registered service agent in most states, so confirm you are permitted before opening it, and arrange resealing and any required W&M notification afterwards

The two wire ID for side A has changed. The dispenser is presenting a different address than it was. Action: establish whether the change was deliberate, since an ID is normally set by a technician; check for a duplicate ID on the loop, which makes two dispensers fight and produces intermittent faults at both; check the ID matches what the site controller expects for this fuelling position; check whether a board swap brought a different stored ID with it; correct the ID and confirm the controller sees the correct position; verify pricing and grade mapping afterwards, because an ID change can attach the wrong prices to the wrong position

29

The valve did not open when commanded. Action: check the valve is receiving its drive signal, which separates an electrical fault from a mechanical one; check the valve coil for an open or shorted winding; check the harness and connector at the valve, including water in the connector; check the valve mechanically for debris, seizure or a failed return spring; check the shear valve below is open, since a closed shear valve gives no flow and can be mistaken for a valve fault; check the dispenser filter, since a blocked filter starves the valve and looks similar; replace the valve only once the drive signal is proven present

30

A catastrophic error has occurred on the VaporVac system. Vapour recovery is not functioning. Action: check the vapour hose and connections first, including for kinks, blockage and damage; check the VaporVac motor for power and for mechanical seizure; check the motor harness and connector; check the VaporVac board for power, communication and water ingress; check for liquid in the vapour path, which is a common cause of repeated failures; vapour recovery is enforced by your local air district rather than federally, so check what downtime and reporting your jurisdiction requires; record the outage, because vapour recovery has its own compliance record separate from the tank

33

Either the emergency stop was activated, or the VaporVac failed on one side. These are very different situations, so establish which before doing anything. Action: check whether the emergency stop is actually latched in, and if so find out why it was pressed before resetting it; do not reset an E stop without establishing the reason, since it may have been pressed for a real emergency; if the E stop is clear, work it as a single side VaporVac failure; check the vapour hose, motor and harness on the affected side; compare the failed side against the working side, which is the fastest diagnostic available on a two sided unit; check the E stop switch and wiring if it reports pressed when it is not

42

Either the price per unit option changed, or a valve is stuck or has timed out. Treat the valve possibility first, because it has consequences and the option change does not. Action: check whether a valve is stuck or failed to operate within its expected time, and if so work it as a valve fault; check the valve drive signal and the coil; check the valve mechanically for debris and seizure; if no valve fault exists, check whether the PPU option was changed and by whom; verify current pricing is correct before allowing sales; check the event log timestamps to separate the two causes

44

The PPU board saw the pump handle on at power up. The dispenser will not authorise with a handle already lifted, which is a safety behaviour rather than a fault. Action: check whether a nozzle is genuinely left up, which is the usual explanation; return the handle to the hung position and power cycle; if no handle is up, check the hang up switch for sticking, damage or water; check the switch harness for a short to ground; check the switch adjustment, since a maladjusted switch reads as lifted; test the switch directly before replacing anything

Action: check whether other dispensers are also disconnected, which separates a site fault from a dispenser fault immediately; check the two wire or network cable and terminations at the dispenser junction box, looking for water and corrosion; check the site controller and its interface board are powered and running; check whether the POS system was restarted or updated, which is a common cause; check the dispenser's address matches what the POS expects; check for a duplicate address on the loop causing intermittent dropouts

4311

The low octane product is flowing but below the rate the blend needs. A blend cannot be held accurately when one leg is starved, so the delivered grade may be off specification. Action: check the dispenser filter on that leg first, since a partially blocked filter is the most common cause; check the shear valve on that leg is fully open, not partly closed; check the STP for that product is running and making normal pressure; check the meter and the blend valve on that leg for debris or partial seizure; check the tank has adequate product and no water at the intake; prove the blend after correcting, because the grade delivered while this was active may not have met specification

4321

A valve is stuck. Depending on which way it is stuck this means no flow, or flow that should not be happening. Action: determine which way it is stuck before anything else, since stuck open is a safety and loss issue and stuck closed is only an outage; if it is stuck open, take the position out of service immediately; check the valve mechanically for debris, scoring or a failed spring; check for contamination in the product, which is the usual cause of repeat sticking; check the dispenser filter condition, since a collapsing filter sheds material into the valve; check the drive is not holding the valve energised through a shorted driver; clean or replace the valve, and address the contamination or the filter will do it again

5047

Reverse flow has been detected. Product moved backwards through the meter. Action: stop using the position until this is understood, since reverse flow can mean product is moving between grades; check the check valve in the meter or the dispenser inlet, which is the usual mechanical cause; check for a leaking or stuck valve allowing back feed from another line; on blenders check the blend valves for leakage between products; check the pulser wiring and direction sensing, since a miswired quadrature pulser reports reverse flow that is not happening; check for a siphon condition pulling product back toward the tank; confirm with an actual dispense once the mechanical cause is cleared

5048

No flow was detected when flow was expected. Action: check the obvious first, whether the tank has product and the STP is running; check the shear valve is open, which is very commonly left closed after service; check the dispenser filter for blockage; check the solenoid or flow control valve is opening, both electrically and mechanically; check the pulser is reporting, since a dead pulser reads as no flow even when product is moving; check the meter for seizure or debris; work from the tank forward rather than starting at the dispenser

5049

Action: treat this as both a loss and a safety issue, and take the position out of service until it is understood; check the solenoid or flow control valve for leakage past the seat, which is the usual cause; check the valve is not stuck open mechanically or held open electrically by a shorted driver; check the nozzle and hose for leakage; check the pulser for false pulses from electrical noise, which reports flow that never happened; check the hang up switch is reporting correctly, since a stuck switch can leave the position live; reconcile against tank inventory to find out whether product actually left
